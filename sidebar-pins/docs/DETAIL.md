# 侧栏置顶 / Sidebar pins

在 DSH 侧栏里补上两件事：把工作区置顶到最前，以及把不同工作区的会话汇总到所有工作区之上的全局置顶区。

## 全局置顶会话

1. 打开任意会话行的「⋯」菜单（或右键），点 **全局置顶**。
2. 侧栏「工作区」标题下方出现 **置顶** 区，排在所有工作区分组之前；区里的行按最近置顶顺序排列。
3. 该会话仍然保留在它自己的工作区分组里，可以照常点开；置顶区只是多一个入口。
4. 点置顶行右侧的「×」，或在同一菜单里点 **取消全局置顶**，即可移除。标题栏可折叠整个置顶区。

当前打开的会话在置顶区里有和原生行一样的选中底色（打开右侧面板时该高亮收起，与原生列表一致）。置顶行可以直接拖拽调整顺序，拖到某行上半/下半会出现插入线；也可以聚焦行后按 Alt+↑ / Alt+↓ 移动一格。顺序保存在本地，取消置顶不影响其他置顶会话。

置顶区只在「按工作区分组 / 工作区树」模式、侧栏展开、且没有在搜索时显示；侧栏收起成图标栏或切到扁平列表时自动隐藏。被全局置顶的会话在它自己的工作区行尾也会带一枚小图钉，所以即使置顶区被折叠或隐藏，置顶状态仍可见。

## 置顶工作区

1. 打开工作区行的「⋯」菜单，点 **置顶工作区**。
2. 该工作区被移到工作区列表最前，并带一枚灰色小图钉；工作区内会话、拖拽、重命名都不受影响。
3. 再次打开菜单点 **取消置顶工作区**，它会回到置顶前紧邻的位置；若原来的后邻工作区已被删除，则停在其余置顶工作区之后。

置顶工作区始终保持在列表最前：手动把某个置顶工作区拖到未置顶工作区之后时，约 150ms 后它会重新回到置顶块内；置顶块内部几个工作区之间的拖拽顺序会被保留。宿主拒绝排序（例如当前连接没有 reorder 权限）时，操作会回滚并显示失败提示。

工作区顺序通过 DSH 原生 `workspaces.insertBefore` 写入工作区注册表，重启后仍然有效，同一 profile 的所有浏览器都看得到。置顶集合本身（哪些工作区被置顶、恢复位置、哪些会话全局置顶、置顶区是否折叠）保存在浏览器 `localStorage` 的 `dsh.sidebar-pins.v1` 下，不跨浏览器同步。

## 实现与限制

- 宿主半身是空插件；功能全部在浏览器半边，不改 DSH 自身文件。
- 两个菜单项都是 `ctx.contextMenus` 的数据贡献，不替换任何自带 UI。
- 置顶区通过 `shell.overlay` 挂载，并把它 portal 进自带工作区浏览区的 `[data-sidebar-list-area]` 滚动容器最前面；插件卸载时移除该宿主节点。自带列表本身不被替换。
- 依赖自带侧栏的两个稳定事实：列表区的 `data-sidebar-list-area` 属性，以及工作区行的 `data-row-key="workspace:…"`。DSH 若重构这两处锚点，需要同步更新 `client.js`。
- 已归档会话、subagent 子会话不进入置顶区；会话被归档时它的置顶记录保留，取消归档后重新出现。
